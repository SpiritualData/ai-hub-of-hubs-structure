# Requirements by arm

What every arm needs from its environment: variables, accounts and API keys, Python extras, programs, services and downloads.
Generated by `python3 scripts/status.py` from the `REQUIRES` declarations on the arms (`hubofhubs/arm_needs.py` holds the
shared ones); do not edit between the markers. Free-tier and rate-limit statements are copied from each vendor's own page and
carry the date they were read; a fact that could not be confirmed there is left out. No value of a variable is ever shown.

To install only what the arms you use need, run `esoi install --package hubofhubs --solution <seat>` (see
[install only what you need](../how-to/install-what-your-seats-need.md)). The default assembly's variables are in `.env.example`
at the repository root.
