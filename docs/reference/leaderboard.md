# Leaderboard

Every check with a rival arm, one row each, generated by `python3 scripts/status.py` from `esoi/results.csv` and `esoi/per_case.csv`. The
selected arm is the one with the highest result on the seat's metric at the latest comparable stage; the rate, interval and two-sided
exact McNemar test come from the same cases, so they are in-sample claims (`[selection] holdout` in `esoi.toml` is an opt-in split into
choosing and reporting cases). How the cases and tests work: [how we measure](../explanation/how-we-measure.md).
